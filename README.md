# Top6MetaA — Bug Tracker

This repository contains **no source code**. It exists solely as a public issue tracker for [Top6Meta](https://top6meta.com/) — a Python framework for the design, generation, and analysis of architected materials and metamaterial structures.

---

## 🐛 Reporting a Bug

1. Click **[Issues](../../issues)** in the top tab
2. Click **New Issue**
3. Select the **Bug Report** template
4. Fill in all fields and submit

Please search existing issues before opening a new one — your bug may already be reported.

---

## ✅ What to include

A good bug report has:
- **Clear steps to reproduce** the problem
- **The topology used** (e.g. Gyroid, Schwarz Diamond, IWP)
- **Screenshots** if the issue is visual

The more detail you provide, the faster we can fix it.
